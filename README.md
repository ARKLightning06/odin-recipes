# odin-recipes
Welcome to my recipe website for practice in learning html through The Odin Project!

## Purpose
This small site is purely for practicing html and css skills as part of [The Odin Project](https://www.theodinproject.com)'s curriculum. The task was to implement a simple website with three different pages for three different recipes. The first version of the project was purely text, but later I came back and added some basic CSS.

## Recipes
I chose 'three' recipes to add. First is the classic chocolate chip cookies, a family recipe. Second is buckeyes, a delicious peanut butter chocolate confection. Third is Smookies, a recipe I discovered recently that takes the best qualities of cookies and smores and smashes them together. And fourth... oh right, there is no fourth...
